ICRC Token Explorer

Internet Computer Protocol ICRC Token Explorer

ICRC Token Explorer is a web application that allows you to easily explore and manage ICRC standard tokens issued on the Internet Computer Protocol network. Users can check various token information and track transaction history.

Key Features

Token List

Check the complete list of tokens issued under the ICRC standard.

Token Details

Check detailed information, statistics, and metadata for each token.

Real-time Data

All data is fetched directly from canisters using the ICP SDK.

Real-time Updates

Provides real-time token information and blockchain interactions.

ICRC-1 Standard

The ICRC-1 standard defines a common interface for fungible tokens on the Internet Computer. This explorer implements all standard methods to provide accurate and up-to-date token information.

Query Methods

  • • icrc1_name() - Token Name
  • • icrc1_symbol() - Token Symbol
  • • icrc1_decimals() - Decimal Places
  • • icrc1_total_supply() - Total Supply
  • • icrc1_fee() - Transfer Fee
  • • icrc1_metadata() - Token Metadata

Account Methods

  • • icrc1_balance_of() - Check Balance
  • • icrc1_transfer() - Transfer Tokens
  • • icrc1_supported_standards() - Standard Information
