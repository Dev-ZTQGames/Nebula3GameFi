Description

Nebula3 GameFi (N3G) is a utility token built on the Internet Computer blockchain using the ICRC-1 standard. It powers the ztq games ecosystem, enabling seamless in-game transactions, rewards, and governance features. N3G is designed for fast, low-cost transfers with built-in security features.
